# Ebbinghaus Reminder

http://ebbinghaus-reminder.windway.dev

A full-stack application for interval-based learning using the Ebbinghaus forgetting curve principle. This project consists of a React frontend, a Spring Boot backend, and a Telegram bot interface.

## Project Structure

* **`/frontend`**: React application built with Vite and Tailwind CSS.
* **`/backend`**: Java Spring Boot application handling core logic and API.
* **`/telegram_bot`**: Python-based bot for user interaction and notifications with Fast API.
* **`/database`**: Docker and SQL configuration for data persistence.
